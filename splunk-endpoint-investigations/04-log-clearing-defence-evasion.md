# Investigation 04: Defence Evasion via Event Log Clearing 

## Executive Summary
This investigation analyses defence evasion activity on an endpoint (`DESKTOP-TBSUDKQ`). Telemetry reveals the adversary executing native administrative utilities (`wevtutil.exe`) via `cmd.exe` to clear the Windows Security event log channel and impair defensive visibility.

---

## 1. Hypothesis
* If the attacker attempts to clear event logs to evade detection, I expect to see process execution of `wevtutil.exe` clearing security/system event logs or native Event ID `1102` ("The audit log was cleared") generated by the Windows Event Log service.

---

## 3. Key Artifacts & IOCs

* **Executed Process:** `C:\Windows\System32\wevtutil.exe`
* **Parent Process:** `C:\Windows\System32\cmd.exe`
* **Parent Command Line:** `"cmd.exe" /F:ON /c wevtutil cl Security > \Windows\Temp\Y1fBZKkz 2>&1`
* **Child Command Line:** `wevtutil cl Security`
* **Event Codes Triggered:** 
  * `4688` (Process Creation for `cmd.exe` and `wevtutil.exe`)
  * `1102` (The Audit Log Was Cleared, generated under `SYSTEM`)
* **Execution Timestamp:** `2026-10-07 19:53:46`
* **Account Context:** `DESKTOP-TBSUDKQ$` (Executed on the endpoint)
* **Temporary Output File Artifact:** `\Windows\Temp\Y1fBZKkz` (Created by the > operator to quietly save command output to disk instead of displaying it on screen)

---

## 4. Conclusion

* **Verdict:** True Positive
* **Severity:** High
* **Framework Mapping:** MITRE ATT&CK T1070.001 (Indicator Removal: Clear Windows Event Logs)
* **Summary:** Confirmed defence evasion activity. The adversary executed `wevtutil cl Security` via `cmd.exe` at `19:53:46` to wipe the Windows Security event log channel. The activity was confirmed by Event Code 1102 and evidence of the attacker saving command output to `\Windows\Temp\`.

---

## 5. Containment

* **Artifact Cleanup:** Permanently delete the temporary file created by the attacker to capture command output and error messages during log erasure.
